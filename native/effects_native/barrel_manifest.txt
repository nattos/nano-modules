# barrel_manifest.txt — effects exposed by the NanoBarrel native plugin.
#
# SOURCE OF TRUTH for which effects the barrel registers. The build
# (gen_barrel_effects.py, driven by CMake) reads this to generate the MSL
# headers + the registration code, and CMake derives the effects_native
# source list from it. Adding an effect to a cared-about bundle = add one
# line here (then rebuild; the WASM bundle build must have produced the
# effect's .spv under build/tmp first).
#
# Columns (pipe-separated):
#   bundle    — informational: which WASM bundle the effect ships in.
#   namespace — C++ namespace == wasm_modules/<namespace>/ source dir.
#   id        — editor module_type (must match the effect's state::init id).
#   display   — inspector display name.
#   abi       — `instance` (class-like: module_init/create/destroy + self)
#               or `legacy` (old free-function init/tick/render; adapted via
#               a native trampoline — file-static state, so correct only
#               single-instance in a native chain. Convert to instance for
#               true per-instance behaviour).
#   shaders   — comma list of registerShaderSPV names. `name` when the SPV
#               variant matches the name; `name=variant` when they differ
#               (variant = the <effect>_<variant>.spv basename suffix).
#   identity  — OPTIONAL 7th column. The literal token `identity` marks an
#               effect that exposes an is_identity() predicate (instance:
#               `int32_t is_identity(void* self)`; legacy: `int is_identity()`).
#               The executor calls it to skip the dispatch and alias
#               input→output when the current state is a pure passthrough.
#               Only for STATELESS effects. Omit the column otherwise.
#
# Lines starting with # and blank lines are ignored.
#

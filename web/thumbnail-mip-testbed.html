Thumbnail Mip / Persistence Testbed — tiered (mem→disk→decode), zoom-aware views, stretching (window.__thumbMip)

Zooming changes the requested mip level. While the new level prefetches (mem→disk→decode), peek() serves the nearest cached tile from another level — drawn at its true frame (gaps/overlap = "stretching"). Cold restart keeps the (mocked) disk tier so tiles return without re-decoding.
